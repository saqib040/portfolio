Distributed File System with Fault Tolerance

A fault-tolerant file storage system built on a Master-Slave architecture, managing data across multiple nodes with file partitioning and replication.

  • Handles concurrent client requests with socket programming and multithreading, plus heartbeat-based failure detection.
  • Recovers lost replicas through replication, self-healing and SHA-256 checksums that protect data integrity.
  • Includes a Flask-based dashboard showing real-time cluster status and storage health.
